# Pronto Gestor 0.8.0 — Windows x64

Para instalação existente, feche o Pronto pela bandeja e execute `Reparar-Pronto-0.8.0.exe`. Ele preserva banco, senha e configurações. O runtime Electron/Node permanece compatível com a versão 0.7.0.

Para instalar do zero, extraia este ZIP e abra `Instalar.cmd`. O script une as partes, valida SHA-256 e abre `Pronto-Gestor-0.8.0-Windows-x64.exe`. O cliente não precisa instalar Node ou Docker.

Novidades: mesas e conta acumulada, balão no + do garçom, combos com componentes por cozinha, limite compartilhado de estoque, entregador com filtros/rota e fila de ações pendentes, HTML inicial do cardápio, planilhas e backups locais.

Em Cardápio, use **Conferir cardápio Loja Dos Sonhos (79 produtos)**. Revise a lista de pendências, os itens que serão desativados e nome/prazo, depois confirme. Os preços foram transcritos do texto do proprietário. Fotos e adicionais não informados não foram inventados; Salgados 175g ficou sem produto vendável por falta de preço. Os acompanhamentos sem porção exata ficam como itens de preparo.

Consulte `OPERACAO-LOCAL-0.8.md` para a apresentação. Pedidos/impressão funcionam no PC e rede local. 4G externo, instalação PWA e GPS no celular dependem de acesso HTTPS ao computador; nenhuma VPS/hospedagem foi publicada nesta atualização.

Elgin i8 USB 80 mm: selecione o driver em Impressão, configure as duas cozinhas e teste fisicamente papel/corte. O build não substitui homologação na impressora real.

Código-fonte: `Pronto-Gestor-Codigo-Fonte.zip` ou a branch `codex/mvp-pronto-gestor` de Marti-yan/GESTOR.
